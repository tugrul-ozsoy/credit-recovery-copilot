# Short user test protocol (about 20 minutes)

Purpose: get attributable, independent evidence of usefulness, including one timed manual-versus-tool comparison on
an identical task. Nothing from a test is reported unless it was actually observed and the participant agreed.

## Task (identical for both conditions)

From the WW International disclosure statement (`data/cases/ww_international/source.htm`, Exhibit B), answer:

1. What is the net distributable value in the Low, Mid and High cases?
2. What do the secured lenders recover in each case, and which class is the fulcrum?
3. If accounts receivable recovered 100% of book in the Low case, how much would the secured recovery change?

## A. Manual (timed)

Open the filing in a browser and answer the three questions with Excel or a calculator. Start the timer when the
filing opens; stop it when all three answers are written down. Record the time and the answers.

## B. With the tool (timed)

Follow the README quick start (or use an already running copy), choose WW International, open a saved run or run a
live extraction, and answer the same three questions. Start the timer when the app page opens; stop it when all
three answers are written down. Record the time and the answers.

(Running B before A biases A toward speed; if only one participant is available, say which order was used.)

Correct answers for checking (from the filing and the engine): net distributable value $119,352k / $143,650k /
$177,911k (filed); secured recovery 7% / 9% / 11% filed (engine 7.3% / 8.8% / 10.9%); fulcrum: the three pari-passu
